## Как применить

Скопировать файлы из архива в корень репозитория `hannamuzyka` с заменой, соблюдая структуру папок, закоммитить и запушить в `master`. GitHub Pages задеплоит автоматически (~1 минута).

```
cp -r hannamuzyka-update/* hannamuzyka/   # или перетащить файлы через веб-интерфейс GitHub
```

## Что изменено

### 1. Битая ссылка 404 → исправлена
- `projects/kadence.html`: кнопка «GitHub ↗» теперь ведёт на `github.com/KyuuketsukiAkado/Kadence-Release` (рабочий репозиторий) вместо несуществующего `/Kadence`.

### 2. Favicon: 529 КБ → 14 КБ
- Новый файл `assets/favicon.png` (192×192, 14 КБ; такой размер ещё и соответствует требованиям Google к favicon в поиске).
- Подключён на всех 4 страницах: `<link rel="icon" type="image/png" sizes="192x192" ...>`.
- Старый `assets/profile/mynotionface.png` больше нигде не используется — его (и другие неиспользуемые исходники) можно удалить из репозитория позже.

### 3. og:image: до 2,7 МБ → 34–95 КБ, 1200×630 JPG
- Новая папка `assets/og/` с 4 превью:
  - `og-home.jpg` (34 КБ) — карточка с портретом и именем
  - `og-kadence.jpg` (95 КБ)
  - `og-shifted.jpg` (95 КБ)
  - `og-blog.jpg` (92 КБ)
- `og:image` и `twitter:image` обновлены на всех 4 страницах; на главной добавлены `og:image:width/height`.
- Побочный фикс: `assets/projects/shifted-hero.jpg` на самом деле был WebP с расширением .jpg — превью соцсетей теперь берёт настоящий JPEG.

### 4. Блог: переключатель языка + корректный lang
- `blog/kadence-ai.html`: добавлена кнопка `#lang-toggle` в шапку — раньше пойманный `lang="en"` из localStorage ошибочно помечал русскую статью как английскую для скринридеров.
- Шапка блога унифицирована с главной: те же 7 пунктов в том же порядке (добавлен «Арт»), все с `data-i18n` — теперь навигация переводится.
- «Связаться» теперь ведёт на `../index.html#connect` (как на главной), а не mailto.
- На `<article>` добавлен `lang="ru"`: статья осознанно русскоязычная и для скринридеров теперь помечена корректно при любом языке интерфейса.

### 5. Мобильная навигация (≤800px) — появилась
- `index.html`, `blog/kadence-ai.html`: добавлена кнопка-бургер `#menu-toggle` и оверлей-меню `#mobile-menu` (на страницах кейсов навигации нет по дизайну — меню там не требуется).
- `css/style.css`: стили меню в конце файла (отдельный отмеченный блок) — панель на весь экран под шапкой, закрытие по ссылке/Escape/ресайзу, `aria-expanded`, блокировка скрола страницы при открытом меню.
- `js/main.js`: блок `initMobileMenu()` в конце файла; безопасно не срабатывает, если элементов нет на странице.
- Меню переводится через существующий механизм i18n (те же ключи `nav.*`).

### 6. Fallback-текст в HTML синхронизирован с `copy.ru`
- 10 расхождений исправлены (0 осталось): секция «Опыт» на главной (смешанный русский/английский текст, который видели поисковики без JS), стрелка в `hero.cta`, `kadence.stat4`, `kadence.p3`, `shifted.p1/p2/p3` (в т.ч. «концепт e-commerce marketplace» → «концепт маркетплейса»).
